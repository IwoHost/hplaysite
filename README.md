# Hplaysite

The site for [Hplay](https://iwohost.github.io/hplaysite/), a click-wheel music
player for Android, built by HostLabo.

This site is plain HTML, CSS and JavaScript with no build step, served by GitHub
Pages straight from `main`.

| Path | What it is |
|------|------------|
| `index.html` | The site |
| `review.html` | A long read on how the player got built |
| `feedback.html` | The beta feedback form, English and Polish |
| `changelog.html` | Every release. Generated by the app repo's `tools/build_changelog.py` |
| `license.html`, `gift.html` | The licence, and the page old supporter links land on |
| `wrapped.html` | Your Year, Wrapped. Opened inside the app; has its own look |
| `site.css` | The look every page except Wrapped shares |
| `fonts/` | The typefaces, served from here so no page asks anyone else for them |
| `img/` | Album sleeves and photos; `img/app/` is the real app, photographed by `tools/shots.js` |
| `tools/` | `shots.js` retakes the app pictures, `contrast.js` checks the pages can be read |
| `music/` | The twenty demo tracks, plus a zip of all of them |

## The demo music

Twenty tracks on six invented compilations, released as HostLabo Tapes. They
were written and synthesised from scratch to give the player something varied
to be tested against. No real artist, band or recording is involved, and every
name and sleeve is made up. Free to download and keep.

## The player

The app itself is not in this repository. It is in beta, not on the
